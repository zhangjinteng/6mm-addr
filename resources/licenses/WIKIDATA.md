# Wikidata Attribution

The bundled `world-places.sqlite` database contains Chinese place labels from
Wikidata matched through the GeoNames ID property (`P1566`).

- Source: https://www.wikidata.org/
- GeoNames ID property: https://www.wikidata.org/wiki/Property:P1566
- License: Creative Commons CC0 1.0 Universal
- License text: https://creativecommons.org/publicdomain/zero/1.0/

Wikidata labels are used as a supplemental source when GeoNames does not
provide a Chinese alternate name.
