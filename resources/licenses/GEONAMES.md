# GeoNames Attribution

The bundled `world-places.sqlite` database contains country, administrative
region, city, and alternate-name data derived from GeoNames.

- Source: https://download.geonames.org/export/dump/
- License: Creative Commons Attribution 4.0 International
- License text: https://creativecommons.org/licenses/by/4.0/

The database is generated by `scripts/build_database.py`. Curated corrections
are tracked separately in `scripts/data/address-overrides.json`.
