# Unicode CLDR Attribution

The bundled `world-places.sqlite` database contains subdivision display names
derived from Unicode Common Locale Data Repository (CLDR).

- Source: https://github.com/unicode-org/cldr
- Data file: `common/subdivisions/zh.xml`
- License: Unicode License v3
- License text: https://www.unicode.org/license.txt

The source release used by the supplemental-name generator is recorded in
`scripts/data/supplemental-names.json.gz`.
